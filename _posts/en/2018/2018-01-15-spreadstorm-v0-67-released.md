This update brings you some bug fixes and game improvements as well as several new levels in the tutorial section of the game.

## Savegame compatibility

This new version is not compatible with old savegames. However, if would like to continue your old savegames, we have made the old build available on different Steam branch named v0.56

To switch to a previous build, follow these simple steps:

1. In your Steam library, right click the game Spreadstorm and select Properties.
2. In the Properties screen, click on the tab BETAS.
3. In BETAS, click the arrow to open the dropdown.
4. From the dropdown, select an old "v0.56" branch and then click Close.

## So what are the key features?

- Reset and save system overhaul: it is harder to break the game with it now.
- 6 new levels extending tutorial section of the game.
- Timer signal behavior totally rewrited, so it is more consistent and less annoying.
- Visual appearance of common and uncapturable nodes improved.
- A lot of bug fixes, small levels changes and performance improvement
