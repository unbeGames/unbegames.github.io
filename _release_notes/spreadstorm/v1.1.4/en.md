### Features:

- Added Continue button to main menu when game is loaded.
- [Keyboard] Arrow keys and Enter work to navigate the UI in addition to WASD and Space. (Required reset controls to default).
- Localized controls window.

### Changes:

- Improved patrol behaviour so it is more predictable now.
- Decreased required energy for nuke action by 15%.
- Increased starting maximum energy from 150 to 175 (will work only on new save).
- Save stats now reset on starting new game+ so you can continue to get achievements with stronger signal.

### Fixes:

- Fixed a bug, when the game suddenly stuck on late levels.
- Optimized memory consumption on long sessions.
- Removed unsued key bindings from controls.
- Fixed different UI bugs in controls window.
- Fixed a bug when patrol just disappered after loading game.
- Fixed an issue when controls window not opened when level was loaded.
