### Changes:

This update addresses several core, performance and visual issues.

- Button "Reset" in main menu renamed to "Reset Level".

### Fixes:

- Fixed an issue when level reset sometimes stuck.
- Some late levels performance optimizations.
- Fixed an issue when some patrol levels completely broke if you stood there long enough.
- Fixed an issue when transfer led to nowhere from first I/O port in level 024.09.
- Fixed some visual bugs in 024.0x levels.
